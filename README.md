# PILLBOX website

A static website for GitHub Pages.

## Publish with GitHub Pages
1. Create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the `music` folder (and optional `assets` folder) to the repository root.
3. In Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for deployment. The site will be at `https://YOUR-USERNAME.github.io/`.

## Add the two demo songs
Upload MP3 files with these exact names into the `music` folder:
- `demo-01.mp3`
- `demo-02.mp3`

The player on the website will then play the files.

## Replace member illustrations
The current member illustrations are original placeholders drawn in SVG in `index.html`. They can be replaced with photographs or custom artwork later.
